# openssl_tracer

> openssl_tracer: TLS plaintext capture using eBPF technology.

This is a sample project that demonstrates tracing the OpenSSL library using eBPF with libbpf. In eBPF programs, since libbpf now supports BTF (BPF Type Format) in the kernel, there's no need to include numerous kernel header files to obtain kernel data structure definitions. Instead, the `vmlinux.h` header file generated by `bpftool` is used, which contains the definitions of kernel data structures.

This sample accompanies the blog post "Using eBPF to Trace SSL/TLS Connections" [Blog Link](https://kiosk007.top/post/%E4%BD%BF%E7%94%A8ebpf%E8%B7%9F%E8%B8%AA-ssltls-%E8%BF%9E%E6%8E%A5/)

![](https://ebpf.io/static/overview-bf463455a5666fc3fb841b9240d588ff.png)

eBPF programs can be loaded into trace points, kernel, and probe points in user-space applications. This capability provides unprecedented observability of both application runtime behavior and the system itself.

## Prerequisites

The operating system version should preferably be greater than 5.x. This sample runs on Ubuntu 5.15.x. Some kernels below version 5.4 may have issues. See https://github.com/iovisor/bcc/issues/2948 for details.

```bash
$ uname -r
5.15.0-30-generic
```

`CONFIG_DEBUG_INFO_BTF = y` - New BPF binaries are only available when this kernel configuration option is set. Ubuntu 20.10 has this option enabled by default.

You need to install libbpf tools. On Ubuntu, run the following command:

```bash
$ sudo apt install libbpf-dev
```

Similar commands exist for other operating systems.

## Build

Run the following commands:

```bash
make ebpf
make build
```

## Run Demo Application

This demo includes a simple SSL communication program in `ssl_client_server`. Running this program provides stable SSL communication data.

```bash
cd ssl_client_server; python3 ./server.py
cd ssl_client_server; python3 ./client.py
```

## Run Tracer

Execute the following command:

```bash
sudo ./openssl_tracer <pid>
```

For tracing the demo application, you can use:

```bash
sudo ./openssl_tracer $(pgrep -f "./client.py")
```
